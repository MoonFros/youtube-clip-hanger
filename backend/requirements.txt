# FairClip backend — core runtime.
# Everything here has prebuilt wheels on Windows/macOS/Linux for Python 3.11-3.14.
#
# About the av pin (>=12,<17): PyAV ships a wheel per Python version, so the
# range has to cover the interpreter people actually run. av 12 stops at cp312;
# cp313 arrived in 13.1, cp314 in 15.1 — pinning to a single major (which we
# used to do) forced a from-source FFmpeg build and failed with "Microsoft
# Visual C++ 14.0 or greater is required". The code supports 12 → 16.
# Note: PyAV has NO 32-bit Windows wheels at all — use 64-bit Python.
fastapi>=0.111
uvicorn[standard]>=0.30
python-multipart>=0.0.9
numpy>=1.26
av>=12.0,<17
pillow>=10.0
httpx>=0.27
yt-dlp>=2024.4.9

# Optional but recommended: a system ffmpeg (NOT a pip package) is used for
# fast preview transcodes / audio extraction when it is on PATH. Without it the
# backend falls back to the slower pure-PyAV path - still fully functional.
#   Windows:  winget install Gyan.FFmpeg      (or: choco install ffmpeg)
#   macOS:    brew install ffmpeg
#   Linux:    sudo apt install ffmpeg

# NOTE: do NOT add piper-tts / espeakng-loader here. Nothing in the code uses
# them (the bookend voice is the vendored meSpeak engine in backend/tts/) and
# their native dependency piper-phonemize has no Windows wheels, which used to
# make `pip install -r backend/requirements.txt` fail on Windows and silently
# drop users onto the old legacy backend. See requirements-ai.txt for optional
# extras.
